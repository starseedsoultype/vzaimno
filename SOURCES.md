# Ссылки источников

В админке откройте «Источники», введите название латиницей и нажмите «Создать ссылку».

Пример: https://t.me/vzaimnosub_bot?startapp=src_podruga

Для каждого канала и каждого повторного размещения используйте новое название, например podruga_20261101.

Допустимы латинские буквы, цифры и нижнее подчёркивание. Максимум 60 символов. Регистр приводится к нижнему.

Источник фиксируется при первом открытии приложения новым автором. Повторные открытия и ссылки других каналов его не меняют. Авторам, зарегистрированным до обновления, источник задним числом не назначается.

Личные ссылки с ref_ продолжают работать и начислять прежние бонусы. Ссылки src_ не начисляют бонус конкретному автору.

Ссылка https://t.me/vzaimnosub_bot?start=src_podruga тоже поддерживается: бот передаёт метку в кнопку открытия приложения. Регистрация учитывается после открытия приложения, а не после одного нажатия Start.

Отчёт доступен только администраторам. Он показывает количество новых авторов, наличие площадки или когда либо добавленного рилса, отправленные подтверждения со статусом ok и получение ответа на своё исходное задание. Показатели отражают текущее состояние данных за всё время. Отклонённые подтверждения не засчитываются. Удаление площадки может изменить показатель заполнения профиля.

Открытие ссылки без запуска приложения не учитывается. Пересылки сохраняют исходную метку. Раздел появляется в новой версии страницы, при необходимости закройте приложение и откройте заново.
